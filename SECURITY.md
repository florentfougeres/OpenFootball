# Security policy / Politique de sécurité

**English** — To report a vulnerability, open a [private security advisory](https://github.com/florentfougeres/OpenFootballBase/security/advisories/new). Please do not include personal data. Details: [docs/en/security.md](docs/en/security.md).

**Français** — Pour signaler une vulnérabilité, ouvrez une [alerte de sécurité privée](https://github.com/florentfougeres/OpenFootballBase/security/advisories/new). N'y mettez pas de données personnelles. Détails : [docs/fr/security.md](docs/fr/security.md).
