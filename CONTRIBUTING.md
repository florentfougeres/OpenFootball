# Contributing / Contribuer

**English** — Contributions are welcome: new countries, parser fixes, bug reports, documentation. Read the [contributing guide](docs/en/contributing.md). **Every documentation or README change must be made in both English and French.**

**Français** — Les contributions sont bienvenues : nouveaux pays, corrections d'analyseurs, rapports de bug, documentation. Lisez le [guide de contribution](docs/fr/contributing.md). **Toute modification de la documentation ou du README doit être faite en anglais et en français.**
